# Frontend - React + TypeScript

Este es el frontend de la prueba técnica, desarrollado con React, TypeScript y Vite. La aplicación se conecta con un backend en C# para mostrar vínculos personalizados por usuario y datos del clima en Bogotá.

##  Funcionalidades

- Login simple por nombre de usuario
- Visualización de vínculos dinámicos por usuario
- Carrusel visual 
- Consulta del clima en Bogotá 
- React Router para navegación

## Tecnologías usadas

- React + Vite
- TypeScript
- React Router DOM
- Bootstrap (clase y estilo)
- Axios
- Context API

##  Cómo correr el proyecto (frontend)

```bash
npm install
npm run dev
```
